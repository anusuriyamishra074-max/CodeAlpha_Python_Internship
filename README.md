CodeAlpha Python Internship

Python Programming Internship Projects – CodeAlpha

This repository contains Python programming tasks completed as part of the CodeAlpha Python Programming Internship.

Projects

Task 1: Hangman Game

A simple text-based word guessing game where users guess a hidden word one letter at a time.

Concepts Used: Random module, while loop, if-else, strings and lists.

Task 2: Stock Portfolio Tracker

A Python program that calculates the total investment value using stock prices and user-entered quantities.

Concepts Used: Dictionaries, user input, basic arithmetic and file handling.

Task 3: Task Automation with Python

A Python script that automatically moves JPG files from one folder to another.

Concepts Used: OS module, Shutil module and file handling.

Task 4: Basic Chatbot

A simple rule-based chatbot that responds to predefined user messages.

Concepts Used: If-elif statements, functions, loops and input/output.
